# \# AI Writer Pro

# 

# AI Writer Pro is an AI-powered document generation platform built using Python, Streamlit, and Ollama. The application helps users generate high-quality content such as reports, resumes, blogs, notes, and creative stories with a simple and interactive interface.

# 

# \## Features

# 

# \* AI-powered content generation

# \* Professional Report Writing

# \* ATS-Friendly Resume Builder

# \* SEO-Friendly Blog Generator

# \* Smart Notes Generator

# \* Creative Story Writing

# \* DOCX Export Support

# \* PDF Export Support

# \* Live AI Response Streaming

# \* Custom Tone Selection

# \* Adjustable Document Length

# 

# \## Technology Stack

# 

# \* Python

# \* Streamlit

# \* Ollama

# \* Python-Docx

# \* ReportLab

# 

# \## Installation

# 

# 1\. Clone the repository

# 

# ```bash

# git clone https://github.com/Rahulsinghraj7/AI-Writer-Pro-.git

# ```

# 

# 2\. Navigate to the project directory

# 

# ```bash

# cd AI-Writer-Pro-

# ```

# 

# 3\. Install dependencies

# 

# ```bash

# pip install -r requirements.txt

# ```

# 

# 4\. Run the application

# 

# ```bash

# streamlit run app.py

# ```

# 

# \## Project Workflow

# 

# 1\. User enters a topic.

# 2\. User selects document type.

# 3\. User chooses tone and length.

# 4\. Ollama generates AI content.

# 5\. Content is displayed in real-time.

# 6\. User downloads the output as DOCX or PDF.
